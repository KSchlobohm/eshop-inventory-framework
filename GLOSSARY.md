# Glossary

| Term | Meaning |
| --- | --- |
| Inventory API | The standalone stock management sample in this repository. |
| ASP.NET Identity | The local account framework; its EF user store and `UserManager` create users and verify passwords. |
| SKU | Stock keeping unit: a product identifier such as `MUG-001`. |
| JWT | JSON Web Token: the bearer token returned by login and required for stock requests. |
| LocalDB | SQL Server's local development database used to store stock and the seeded user. |
